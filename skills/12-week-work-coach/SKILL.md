# 12周工作教练

把用户确认的结果方向转成 12 周计划，再用周行动、执行计分和周期复盘修订做法。一般季度目标可交由 `goal-planner`。用户仍在探索人生方向时，优先处理相应的人生定位或人生设计问题。

## 按需求选择方法卡

| 用户想推进的事 | 先读 |
| --- | --- |
| 把生活或职业愿景同周期方向对齐 | [愿景与方向](references/vision-alignment.md) |
| 设定周期结果和到期周次 | [周期计划](references/goal-plan-building.md) |
| 回看上周并挑出本周到期行动 | [周计划与每日查看](references/weekly-routine.md) |
| 计算执行分数或诊断卡住的原因 | [执行计分](references/execution-score-diagnosis.md) |
| 为关键工作、杂务和恢复安排时间 | [时间块](references/performance-time-design.md) |
| 准备小组每周互助复盘 | [同伴复盘](references/weekly-accountability-meeting.md) |
| 缩小、调整或重谈没履行的行动承诺 | [承诺复查](references/commitment-review.md) |
| 理清首周期节奏或做第 13 周回顾 | [周期复盘](references/cycle-review.md) |

每次优先用当下所需的一张卡。结果目标、行动表现和现实容量分别呈现。没有记录时，先标出缺项并给一个能开始的小步，再问最有用的问题。用户提供旧计划时先确认是否沿用。用户请求 Notion 记录或外部安排时使用已支持的对应 Skill 及其授权流程。

方法参考 Brian P. Moran 与 Michael Lennington 的《The 12 Week Year》。公开方法卡使用通用场景与自拟示例。
