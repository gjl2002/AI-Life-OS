# A/B/C 方案

先确认设计主题和时间跨度。可以用五年作为构想窗口，实际需要较短时按用户选择调整。

| 方案 | 构想起点 |
| --- | --- |
| A 现实延展 | 从目前的生活或工作继续发展 |
| B 替代路线 | 假设当前主路径结束，想象另一个可投入的方向 |
| C 理想构想 | 暂放收入或外界期待的顾虑，描述更向往的日常，再标出回到现实时要面对的约束 |

每案用一个短标题、工作与生活里程碑、所需资源和两三个探索问题描述。由用户评价吸引力、价值适配、可行性、信心和最大代价。未知项标待验证。交付时并排呈现明显不同的方案，并为用户愿意继续的方案标一个原型问题。可以先共写一案，再按用户节奏补齐。
