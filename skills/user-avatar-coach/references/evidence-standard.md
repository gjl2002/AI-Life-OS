# Evidence Standard

## Evidence Levels

Level 1: 一手强证据
- interview transcript
- private chat
- sales consultation
- direct user feedback
- delivery feedback from a real user

Level 2: 行为与互动信号
- comments
- group discussion
- form response
- purchase record
- consultation frequency
- repeated questions before purchase

Level 3: 业务背景材料
- commercial positioning
- product docs
- offer design
- sales page
- existing avatar database
- past content
- built-in theory library as method support only

Level 4: 外部参考
- competitor comments
- public discussions
- industry reports
- public articles or videos

## Certainty Labels

Use these labels:
- 已确认事实: directly supported by Level 1 or strong Level 2 evidence.
- 合理洞察: synthesized from multiple facts or one strong fact plus business context.
- 待验证假设: plausible but not yet supported by enough user evidence.

## Quote Rules

Preserve user quotes when:
- emotion is visible
- the sentence reveals a hidden objection
- the user describes a concrete scene
- the wording can be used in sales or content
- the phrase repeats across multiple users

Do not fabricate quotes. If paraphrasing, label it as paraphrase.

## Formal Avatar Threshold

Produce a formal avatar only when there is at least one of:
- multiple Level 1 materials showing repeated patterns
- one rich Level 1 material plus strong Level 2 support
- existing Notion avatar evidence plus new direct user evidence

Otherwise produce a hypothesis avatar.

Before calling an avatar formal, run `evidence-audit.md`. Important claims must be traceable to source material and labeled as 已确认事实, 合理洞察, or 待验证假设.

## Common Failure Modes

Avoid:
- replacing evidence with demographic stereotypes
- calling "25-35, first-tier cities, self-growth" a real avatar
- over-generalizing from one intense story
- mixing buyer persona and user persona without explanation
- presenting business hopes as user facts
- presenting theory-library concepts as customer evidence
- hiding missing evidence
- using business positioning, theory, or competitor examples as proof of actual user psychology
