# Naming And Word-Of-Mouth Assets

Use this when a product, course, training camp, service, AI agent, template, or feature needs a public name, first-impression check, sharing hook, referral sentence, or experience ending.

## Core Principle

```text
名字是用户接触产品前的第一体验；口碑是用户离开产品后替你传播的一句话。
```

Do not treat naming as decoration. A name is a verbal summon: it helps users recognize, remember, call, and share the product.

## Name Radar

| Dimension | Question | Product Meaning |
| --- | --- | --- |
| 可叫出 | Can a user say it out loud without explanation? | oral transmission |
| 可记住 | Can it stick after one exposure? | memory asset |
| 可召唤 | What emotion, scene, or promise does it call up? | first impression |
| 有文化资产 | Does it borrow from shared stories, symbols, metaphors, or collective memory? | cultural leverage |
| 有偏见 | Does it clearly choose a world view or user identity? | positioning |
| 不隔绝 | Does it invite the target user rather than scare them away? | accessibility |
| 占问题 | When the problem appears, does this name come to mind? | name occupancy |

## Bad Name Signals

- It is easy to see but hard to say.
- It explains an internal system instead of calling up the user's problem or desired result.
- It sounds technically correct but emotionally cold.
- It has no scene, promise, identity, or cultural association.
- It exposes an internal codename before users understand why they should care.
- It makes target users feel the product is too difficult, too corporate, too childish, or not for them.

## Cultural Asset Check

For each candidate name, write:

```markdown
名字:
用户会怎么念:
它召唤的画面/情绪:
它借到的文化资产:
它可能隔绝的人:
它对应的问题/场景:
更口语的版本:
风险:
```

The strongest name is not necessarily the cleverest. It is the one users can call, remember, and repeat in the moment the problem appears.

## Word-Of-Mouth Design

Word of mouth is not an accidental slogan. It is a sentence the product experience is designed to make users say.

Ask:

```markdown
我们把哪件事做过头:
用户在第几个触点感到超预期:
他会忍不住对朋友说哪句话:
这句话是否口语、短、稳定、可重复:
这句话和产品峰值/终值是否一致:
```

Good word of mouth is auditory. It should sound like something a user would actually say, not like a visual slogan or brand manifesto.

## Relation To Experience Design

- **One glance**: the name must let users quickly see "this is for my goal".
- **Journey map**: the name should match the user's arrival reason and remembered problem.
- **Tolerance floor**: a strong name cannot compensate for broken basics.
- **Peak**: the over-delivered moment creates the user's desire to tell others.
- **End**: the ending should hand the user a clean sentence to remember and repeat.
- **Service blueprint**: backstage work should intentionally create the over-delivery that supports the word-of-mouth sentence.
