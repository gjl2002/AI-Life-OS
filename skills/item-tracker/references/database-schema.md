## 新增 select 选项命令示例（必须列全原选项）

产品库品类新增「耳机/相机」之外的新品类（如"平板"）：
```
ALTER COLUMN "品类" SET SELECT('笔记本':red, '鼠标':red, '手环':red, '显示屏':red, 'Ipad':red, '键盘':red, '麦克风':purple, '手机':pink, '插件':gray, '拓展坞':brown, '耳机':default, '相机':yellow, '平板':blue)
```
⚠️ 列全全部原选项 + 新选项，否则覆盖丢失。
