## 新增 select 选项命令示例

品类新增「休闲裤」：
```
ALTER COLUMN "品类" SET SELECT('外套':orange, '羽绒服':gray, '卫衣':brown, '毛衣':red, '长袖':default, '短袖':yellow, '短裤':pink, '牛仔裤':gray, '板鞋':blue, '运动鞋':default, '洞洞鞋':green, '斜挎包':purple, '休闲裤':blue)
```
⚠️ 必须列全原选项 + 新选项，否则会覆盖丢失。
