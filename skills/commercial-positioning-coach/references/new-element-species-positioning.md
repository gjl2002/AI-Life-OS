# New Element To New Positioning

Use this when the user is deciding whether AI, a new tool, a new platform, a new product mechanism, or a new commercial model changes their life/business positioning.

## Core Question

```text
这是旧身份加新工具，还是一个新定位物种？
```

Examples:

- 博士 + AI: may be faster research, or a new AI-native research operator identity.
- 内容创作者 + AI: may be faster writing, or a new personal-context product system.
- Notion 模板 + AI: may be better templates, or a continuous feedback system.

## Positioning Radar

| Dimension | Question |
| --- | --- |
| 自我身份 | Does the user still introduce themselves the same way? |
| 服务对象 | Does the first user/customer change? |
| 解决问题 | Is the problem deeper or different than before? |
| 方法系统 | Does the method become a new loop, not just faster execution? |
| 资源结构 | Does the user now rely on new data, AI context, community, tools, or partners? |
| 产品/作品形态 | Does the output move from content/template/service to system/agent/platform/community? |
| 商业关系 | Does the customer relationship become ongoing, co-created, or feedback-based? |
| 增长方式 | Does growth come from a new loop rather than the same content funnel? |

## AI Life-System Lens

For AI life-system work, do not frame the direction as "Notion + AI" unless the product really remains a template/tool.

Possible new-positioning statement:

```text
真实记录成为上下文，AI 成为理解引擎，复盘成为持续反馈机制。
```

Use this only when evidence shows the user is building a repeatable feedback loop, not merely adding AI-generated text to a static workspace.
