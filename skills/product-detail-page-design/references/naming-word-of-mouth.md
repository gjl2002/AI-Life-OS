# Naming And Word-Of-Mouth For Sales Pages

Use this when a product-detail page needs a product name, hero promise, memorable line, testimonial angle, or referral sentence.

## Core Rule

```text
销售页首屏解决名字能不能召唤用户；销售页后半段解决用户愿不愿意替你说一句话。
```

A good sales page does not only explain the product. It gives the buyer a name and a sentence they can remember, repeat, and use to justify the decision.

## Hero Name Check

For the first image, check:

- Is the product name easy to say out loud?
- Does it summon the buyer's problem, desired identity, or future result?
- Does it have emotional warmth or cultural association?
- Is it too internal, technical, abstract, or hard to spread?
- Does the subtitle repair the name if the name is still unfamiliar?

If the product's internal name is weak for public selling, use category-level language in the hero and keep the internal name secondary.

## Word-Of-Mouth Sentence

Before writing testimonials, outcomes, or CTA, draft:

```markdown
用户体验后会对朋友说:
他为什么会这么说:
是哪一个超预期体验支撑这句话:
销售页哪一页证明这句话:
```

This sentence must be oral, short, stable, and buyer-like. It should not sound like brand copy.

## Page Placement

- **Hero**: name + desired result.
- **Cognitive conflict**: make the old problem nameable.
- **Mechanism**: show why this product can create the promised sentence.
- **Proof/testimonials**: select evidence that supports the same word-of-mouth sentence.
- **Outcomes**: show what the buyer will own or complete.
- **Final CTA**: repeat the same public-facing name and promise.

## Guardrails

- Do not write a clever slogan without a product moment that proves it.
- Do not make users memorize an internal system name before they understand the result.
- Do not use hard-to-pronounce English/technical terms as the only public name.
- Do not let every page invent a new product promise.
- Do not claim users will recommend it unless evidence or a designed over-delivery point supports that.
