# Goal Opportunity Radar

Use this before committing a quarterly goal when the user is choosing between goals, designing a major objective, or asking whether a direction is worth focusing on. The goal is to prevent a plan that is executable but strategically low-energy.

## Lightweight Table

```markdown
候选目标:
点:
  未来约三个月能交付什么:
  可行性:
线:
  这个目标服务哪条长期成长线:
  增长/衰退信号:
面:
  哪个平台/生态/资源会放大它:
  赋能方式:
体:
  背后趋势:
  是否上升:
势:
  现在做是否顺势:
敌人:
  执行阻力 / 竞争阻力 / 趋势阻力 / 定位错位:
目标决策:
  选为P1 / 降为项目 / 先验证 / 延后 / 放弃:
```

## Use Rules

- Keep this radar lighter than full strategic positioning. It should shape goal selection, not replace goal planning.
- A valid quarterly goal still needs a clear done state and first-week action. Strategic momentum cannot excuse vague execution.
- If a goal is only a doable point, ask whether it can be reframed into a stronger line.
- If the goal is exciting but cannot produce any quarterly artifact, rhythm, experiment, or reviewed result, extract a smaller next-three-month experiment or move it into positioning exploration.
- If multiple goals compete, prioritize the one that strengthens a long-term line, is amplified by an active surface, and has a realistic first-week action.

## Decision Labels

- `P1目标`: high strategic momentum and executable within the next roughly three months.
- `项目化`: useful point, but better nested under another goal.
- `先验证`: promising line/surface/body, but evidence is thin.
- `延后`: real value, but timing or capacity is wrong.
- `放弃/暂停`: low momentum or wrong structure.
