# Built-in Design Principles

This skill is self-contained. Use the following principles directly; do not require external poster, template, or magazine-layout skills.

## Commercial poster hierarchy

Apply these when each image needs immediate attention and a clear selling focus:

- Define one visual focal point before designing the page.
- Decide whether the page should feel like a finished commercial poster or an information card; hero pages usually need the former.
- Reserve safe zones around edges, page numbers, CTAs, and export crops.
- Keep a deliberate typography space: headline, deck, proof, and CTA should not fight for the same area.
- Use a single dominant subject or diagram per page; supporting elements must serve it.
- Specify the page's mood and palette before adding decoration.
- Use depth, light, material, and perspective when the benchmark relies on cinematic or premium visual energy.
- Build campaign-series consistency across the full image set: repeated numbering, footer, grid, accent colors, card rules, and visual motifs.
- For generated supporting imagery, request predictable negative space for deterministic text overlays.
- Design variations only after the core hierarchy is correct.

## Chinese marketing readability

Apply these to make pages readable on mobile and suitable for Chinese social-commerce browsing:

- Prefer short Chinese lines, high-information bullets, and visible keyword emphasis.
- Avoid long unbroken paragraphs; split dense copy into cards, rows, labels, or diagrams.
- Use strong contrast for body text and never reduce type just to fit more content.
- Treat the set as a carousel/detail-page campaign: each image should be understandable alone and stronger in sequence.
- Keep brand assets consistent: palette, type scale, icon style, section labels, naming, and export order.
- Use platform-aware exports: consistent width, readable portrait pages, numbered filenames, and a contact sheet for review.
- Batch-produce and inspect the whole set rather than polishing one page in isolation.
- Customize every reference pattern to the user's brand; never reuse a template look as-is.
- Favor visual focus over text-heavy promotion; promotional pages should deliver value before asking for action.
- Track missing commercial facts explicitly instead of filling them with generic urgency.

## Editorial layout rhythm

Apply these when a page needs authority, explanation, or premium intellectual texture:

- Let the headline own the page; subheads and body copy should clearly support it.
- Use editorial contrast: oversized claim, small technical labels, restrained body copy, and deliberate whitespace.
- Use a disciplined grid. Align cards, rules, diagrams, and captions to visible page structure.
- Create rhythm across the image set by alternating dense information pages with spacious hero/transition pages.
- Use numbered sections, eyebrows, captions, and pull-quote style fragments to make complex ideas scannable.
- Make body copy opinionated and specific, not filler.
- Use typographic contrast without importing unrelated aesthetics such as cream newsprint or newspaper styling unless explicitly requested.

## Product-detail synthesis

When designing a product-detail image set, combine the three modes like this:

- Use commercial hierarchy for the opening hero, mechanism claim, bundle, price, and CTA pages.
- Use Chinese marketing readability for audience diagnosis, outcomes, curriculum, FAQ, and rights pages.
- Use editorial rhythm for belief shifts, authority/proof, system philosophy, and explanation-heavy pages.
- If a page feels crowded, split it or increase height; do not shrink type.
- If a page feels decorative but unclear, remove effects until the central message is obvious.
- If a page feels clear but visually weak, switch to visual-first production or rebuild the main visual moment.
- If a page feels informative but not persuasive, add contrast: old way vs new way, problem vs mechanism, input vs output, or before vs after.
