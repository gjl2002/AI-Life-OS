# New Element To New Species Radar

Use this when a product idea introduces AI, automation, community, IP, commerce, finance, data, a new channel, a new service role, or any cross-industry mechanism.

## Core Judgment

```text
新要素的价值，不是看它新不新，而是看它有没有改变产品底层逻辑。
```

Two types:

- **优化型新要素**: improves experience, cost, efficiency, quality, or convenience while the product identity stays the same.
- **变革型新要素**: changes value structure, resource structure, business model, growth path, user relationship, or product identity. It may look similar in the frontstage, but the backstage logic is different.

## Seven Checks

| Dimension | Question | Optimization Signal | Transformation Signal |
| --- | --- | --- | --- |
| 用户价值 | What value does the user get now? | faster/better old result | new result or new reason to use |
| 使用方式 | How does the user use it? | same path, less effort | new behavior loop or trigger |
| 资源结构 | What resources make it work? | same resources plus tool | new data, IP, capital, community, partner, or AI context layer |
| 收入来源 | How does it make money? | same revenue with better margin | new revenue stream or monetization object |
| 增长方式 | How does it grow? | same channel with higher conversion | new channel, network effect, IP, member loop, or user-as-distributor |
| 用户关系 | What is the user's role? | buyer/user only | user becomes contributor, investor, member, data source, operator, or co-builder |
| 产品身份 | What is the product now? | old product plus feature | a new category or system |

## AI Product Rule

For AI-related products, do not stop at "AI helps generate, summarize, or automate." Ask:

- Does user history become durable context?
- Does AI become an understanding engine rather than a writing tool?
- Does review become a continuous feedback mechanism?
- Does the product move from static artifact to dynamic system?
- Does the user relationship change from one-time purchase to ongoing co-evolution?

For AI context or personal-system offers, a useful distinction is:

```text
Notion template + AI prompts = usually optimization.
Real records as context + AI as understanding engine + review as feedback loop = possible new species.
```

## Scoring

Score each changed dimension:

- `0`: not changed or unsupported
- `1`: plausible but thin evidence
- `2`: clearly changed with evidence

Interpretation:

- `0-4`: optimization-type new element
- `5-9`: transition upgrade; validate before claiming new species
- `10-14`: strong new-species potential, if demand and delivery evidence also exist

Species score does not replace opportunity score. A new species can still fail if demand, first user, trigger scene, or delivery fit is weak.
