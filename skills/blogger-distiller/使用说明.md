# 博主内容蒸馏器 —— 使用说明

## 这是什么

一个 Codex Skill。给一份小红书博主的数据 Excel，自动完成从数据分析到内容生成的完整链路：

```
Excel数据 → 选题矩阵 → DNA提取 → 爆文模型 → 飞书报告 → 风格Skill → 100个选题+正文
```

**适合谁用**：想快速拆解一个博主的选题逻辑和内容模式，然后自己批量出内容的人。

---

## 你需要准备

### 1. Codex
- 将本 Skill 安装到 Codex 可读取的 Skills 目录
- 需要能读取用户提供的 Excel 文件；若要自动处理表格，当前环境还需具备相应表格能力

### 2. 小红书博主数据 Excel
用小红书爬虫抓取的数据，表头可以是中文列名，需要包含以下列：

| 列位置 | 内容 | 说明 |
|--------|------|------|
| 第2列 | 笔记类型 | 视频/图文 |
| 第3列 | 笔记标题 | 完整的标题文本 |
| 第4列 | 笔记内容/正文 | 正文或视频描述 |
| 第5列 | 点赞量 | 数字 |
| 第6列 | 收藏量 | 数字 |
| 第7列 | 评论量 | 数字 |
| 第8列 | 分享量 | 数字 |

> 如果用本技能包自带的 `xhs-scraper` 抓取，导出的 Excel 格式刚好匹配。

### 3. 飞书连接（可选）
- 默认可以交付 Markdown 文件
- 只有希望自动创建飞书文档时，才需要已连接且有权限的飞书集成

## 安装方法

## 安装与调用

在 Codex 中安装本套件后，该 Skill 位于 `~/.codex/skills/blogger-distiller/`。若单独安装，请放入当前 Codex 使用的 Skills 目录。

### 第1步：启动技能

调用 `$blogger-distiller` 后，附上 Excel 文件或提供当前环境可访问的文件路径。

### 第2步：确认博主信息
AI 助手会读取 Excel，展示基本统计数据（总笔记数、均赞、千赞以上等），然后问你三个问题：
- 博主叫什么？
- 他是做什么的？
- 你想从他身上学到什么？

如实回答即可。如果只想要选题和内容规律，说"选题和内容都要"。

### 第3步：自动分析（约10-15分钟）
Skill 会按流程完成：
1. **选题矩阵**：把博主的笔记分成大栏目+子类，每类提炼标题公式
2. **DNA提取**：提取博主的思维模型、选题公式、论证路径
3. **爆文模型**：提炼5个以上可复用的爆文公式，每个配操作步骤

### 第4步：查看分析报告
分析完成后，默认交付包含选题矩阵、DNA、爆文模型和标题句式库的 Markdown 报告。若你要求飞书文档，且已连接相应集成，再将报告写入飞书。

### 第5步：交互测试
AI 助手会邀请你测试：你给一个模糊的选题想法，它用提炼出的内容模型生成标题、大纲和正文。可以多测几个想法验证效果。

### 第6步：生成博主风格 Skill
确认效果后，AI 助手会生成一个博主风格 Skill 草稿，供你审阅；未经确认不自动安装或分享。

### 第7步：100个选题
最后输出 100 个选题（按博主栏目分布），可以直接当内容日历用。

## 输出物一览

| 序号 | 输出 | 格式 |
|------|------|------|
| 1 | 赛道/博主分析报告 | Markdown 文件；可选飞书文档 |
| 2 | 选题矩阵（X大栏目×N子类）| 报告内 |
| 3 | DNA提取（思维模型+论证路径）| 报告内 |
| 4 | 爆文模型（≥5个+决策树）| 报告内 |
| 5 | 标题句式库（12个已验证句式）| 报告内 |
| 6 | 博主风格 Skill 文件 | 经用户确认后交付；安装位置按当前环境配置 |
| 7 | 100个选题 + N篇正文 | Markdown 文件；可选飞书文档 |

## 常见问题

**Q: Excel 里不只有一个博主？数据是从搜索结果抓的怎么办？**
A: 可以用"赛道蒸馏"模式。告诉 AI 助手 "用赛道蒸馏"，它会按整个赛道（而非单个博主）来分析内容规律。

**Q: 飞书文档创建失败？**
A: 只有使用飞书集成时才需要相应连接和权限。默认交付 Markdown 文件。

**Q: 分析结果太模板化？**
A: 这个 Skill 的核心逻辑是"从实际数据中归纳，不照搬模板"。如果结果不满意，可以在每一步给 AI 助手更具体的反馈——比如"标题公式太宽了，再细化一下"。

**Q: 需要什么 Python 环境？**
A: 若当前环境需要用 Python 处理 Excel，可安装相应表格依赖（例如 pandas、openpyxl）：`pip install pandas openpyxl`

**Q: 适用于抖音/公众号等其他平台吗？**
A: 目前只针对小红书的数据格式和内容特征做了优化。其他平台的数据可以试，但分析质量可能打折。
