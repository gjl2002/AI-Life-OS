# 商业定位阶段审计

## 工作记录

```markdown
当前阶段：
本轮时间：
上游人生约束：
已确认事实：
初步洞察：
待验证假设：
关键冲突：
缺失证据：
下一个问题或验证：
证据强度：弱 / 中 / 强
```

## 证据等级

- `已确认事实`：多个真实客户、行为、成交、交付结果或持续市场信号支持。
- `初步洞察`：一到两个案例或部分市场证据支持。
- `待验证假设`：逻辑合理但尚未通过客户或市场检验。
- `无证据主张`：只有定位语言，没有相关证据。

## 核心门槛

- 具体人群：冷用户能认出自己，不只是“年轻人”“成长型人群”。
- 具体场景：知道问题何时发生、由什么触发。
- 具体问题：有当前替代方案、失效点和现实代价。
- 价值机制：说明变化为什么会发生，不只是框架、工具或产品名称。
- 产品假设：能够承载价值机制，且明确哪些细节仍需产品类 Skill 验证。
- POV：有经历或产品选择支撑，但不代替需求证明。
- 相关差异：影响客户选择或结果，而不是装饰性表达。
- 市场验证：客户、内容、咨询、销售、收入或持续对标信号至少存在一类。
- 更新机制：知道什么新证据会触发重新定位。
- 下游边界：知道接下来需要用户、产品或内容 Agent 深入什么，不在定位阶段提前完成详细执行。

缺少关键市场证据时，只输出商业定位假设地图。
