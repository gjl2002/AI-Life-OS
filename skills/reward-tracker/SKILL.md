本 Skill 使用 `$ai-life-system-init` 定位用户自己的 Notion 结构。执行前先运行 `scripts/runtime.py status`；状态为 `needs_init` 时先引导用户完成初始化。对本次操作涉及的每个概念运行 `scripts/runtime.py resolve --concept <key>`，只使用 Runtime 返回的目标 Data Source ID。读取该 Data Source 的实时 Schema，并在写入前运行 `scripts/runtime.py check-write` 校验本次属性、选项和 relation。

创建时必须让当前 Notion connector 将新页面的 parent 指向已解析的 Data Source；写入后回读确认 parent 和属性。若概念未找到、结构不兼容、候选不唯一或 connector 无法确认 parent，应停止该写入并说明原因，不得猜 ID、扫描无关空间或复制已有个人记录。以下正文中的数据库路径、字段名、选项和默认值若与用户实时 Schema 不一致，均视为示例而非要求；只有语义和字段类型明确匹配时才映射，否则询问或安全停止。仅读取本次任务所需的数据；不得将用户本地索引、凭据、页面 ID 或个人样例打包发布。

# Reward Tracker — Notion 奖励管理

## 数据库

|---|---|---|

**类型选项**（select，不新建）：健康、成长、生活、娱乐、放松、美食、旅行

**状态选项**（status）：未兑换 → 已兑换 → 已使用

## 场景一：创建奖励

用户说"我要奖励自己一个XX""达成XX目标就去XX"。

### 执行流程

1. 在 Runtime 已解析的用户 Data Source 中直接创建新记录；不复制现有记录。

2. **搜索目标**（如用户提到目标）：用 `notion_ai_search`（data_source_url=目标数据库）按用户说的目标关键词搜。
   - 找到 → 记录目标页面 URL
   - 没找到 → 不关联，不新建目标

3. **搜索并上传封面图**：
   - `image_search` 搜 `"<奖励名称>" 产品图 高清`，选一张最能代表这个奖励的图
   - 追踪直链：`curl -sL -o /dev/null -w "%{url_effective}" "<短链>"`
   - 在 update 时用 `cover` 参数传直链 URL

4. **判断类型**：根据奖励语义匹配：
   - 运动/健身/体检 → 健康
   - 买书/学习课程/技能提升 → 成长
   - 买东西/电子产品/日用品 → 生活
   - 游戏/演唱会/电影/娱乐 → 娱乐
   - 按摩/SPA/躺平/休息 → 放松
   - 吃大餐/美食/探店 → 美食
   - 旅行/出游/酒店 → 旅行

4. **一次性 update 属性**：

```json
{
  "名称": "<奖励名称>",
  "状态": "未兑换",
  "类型": "<类型>",
  "所需金币": <数字>,
  "目标": ["<目标页面URL>"],
  "奖励兑换记录": null,
  "奖励使用记录": null
}
```

新页面只写本次记录明确提供的值；未提供的可选字段留空，不沿用其他记录的属性或正文。

5. **验证**：fetch 新记录确认落库。

## 场景二：兑换奖励

用户说"兑换这个奖励""我要兑换XX"。

### 执行流程

1. **找到奖励**：用 `notion_ai_search`（data_source_url=奖励数据库）按名称搜。
2. **更新奖励状态**：`notion_update_page`，`状态` = "已兑换"。
3. **创建兑换记录**：
新页面只写本次记录明确提供的值；未提供的可选字段留空，不沿用其他记录的属性或正文。
   - update：`名称` = 奖励名称 + "兑换"，`date:兑换日期:start` = 今天，`date:兑换日期:is_datetime` = 0，`奖励` = [奖励页面URL]
4. **验证**：确认奖励状态已改为"已兑换"，兑换记录已创建并关联。

## 场景三：使用奖励

用户说"使用这个奖励""我用了XX奖励"。

### 执行流程

1. **找到奖励**：用 `notion_ai_search`（data_source_url=奖励数据库）按名称搜。
2. **创建使用记录**：
新页面只写本次记录明确提供的值；未提供的可选字段留空，不沿用其他记录的属性或正文。
   - update：`名称` = 奖励名称 + "使用"，`date:使用日期:start` = 今天，`date:使用日期:is_datetime` = 0，`奖励` = [奖励页面URL]
3. **更新奖励状态**：`notion_update_page`，`状态` = "已使用"。
4. **验证**：确认奖励状态已改为"已使用"，使用记录已创建并关联。

## 不碰

- **公式字段**（colour、概览、消耗金币、最近使用日期、使用次数、剩余道具、兑换次数、最近兑换日期）：Notion 自动算
- **按钮字段**（使用、兑换）：API 不触发按钮，手动 update 状态即可
