## 用户自己的 Notion 接入

本 Skill 使用 `$ai-life-system-init` 定位用户自己的 Notion 结构。执行前先运行 `scripts/runtime.py status`；状态为 `needs_init` 时先引导用户完成初始化。对本次操作涉及的每个概念运行 `scripts/runtime.py resolve --concept <key>`，只使用 Runtime 返回的目标 Data Source ID。读取该 Data Source 的实时 Schema，并在写入前运行 `scripts/runtime.py check-write` 校验本次属性、选项和 relation。

概念映射：`media, relationship_circle`。

创建时必须让当前 Notion connector 将新页面的 parent 指向已解析的 Data Source；写入后回读确认 parent 和属性。若概念未找到、结构不兼容、候选不唯一或 connector 无法确认 parent，应停止该写入并说明原因，不得猜 ID、扫描无关空间或复制已有个人记录。以下正文中的数据库路径、字段名、选项和默认值若与用户实时 Schema 不一致，均视为示例而非要求；只有语义和字段类型明确匹配时才映射，否则询问或安全停止。仅读取本次任务所需的数据；不得将用户本地索引、凭据、页面 ID 或个人样例打包发布。

# Film Tracker — Notion 影视录入

## 数据库

- **目标数据源**：以 Runtime 对 `media` 的解析结果为准

## 输入解析

从用户自然语言中提取：

| 字段 | 必填 | 默认值 |
|---|---|---|
| 作品名 | 是 | — |
| 观看日期 | 否 | 今天 |
| 状态 | 否 | 看完 |
| 同行人 | 否 | 不填 |
| 个人评分 | 否 | 留空，用户自己填 |

如果作品名有歧义（同名多版本），先向用户确认。

## 执行流程（照此执行）

### 1. 直接新建记录


**禁止：**
- ✗ 不要复制模板页

### 2. 检索作品信息

用 `general_search` 并行搜索：
- `"<作品名>" 导演 主演 上映日期 剧情简介`
- `"<作品名>" 豆瓣`

提取：导演、主演名单、上映日期、剧情简介、豆瓣链接、豆瓣当前评分。
同时判断：分类（电影/电视剧/动漫/综艺）、主题标签（多选）、语言（国语/英语/日语/韩语）。

### 3. 上传海报

**用正式宣传海报，不用剧照截图。**

1. 用 `image_search` 搜 `"<作品名>" 电影海报 正式海报`
2. 图片返回的 URL 是 `aka.doubaocdn.com/s/xxx` 短链，**先追踪直链**：
   ```bash
   curl -sL -o /dev/null -w "%{url_effective}" "<短链>"
   ```
3. 用 `notion_create_attachment`，`source_url` = 直链，`filename` = `"<作品名>-海报.jpg"`
4. 拿 `file_upload_id`

### 4. 一次性 update 属性

```json
{
  "影视作品": "<作品名>",
  "分类": "电影",
  "状态": "看完",
  "导演": "<导演>",
  "主演": "<主演名单，顿号分隔>",
  "剧情简介": "<简介>",
  "date:上映日期:start": "YYYY-MM-DD",
  "date:上映日期:is_datetime": 0,
  "date:观看日期:start": "YYYY-MM-DD",
  "date:观看日期:is_datetime": 0,
  "主题": ["喜剧"],
  "语言": "国语",
  "豆瓣评分": 6.6,
  "豆瓣链接": "https://movie.douban.com/subject/xxx/",
  "剧照": [{"type":"file_upload","file_upload":{"id":"<file_upload_id>"}}],
  "一起观看的朋友": null
}
```

新页面只写本次记录明确提供的值；未提供的可选字段留空，不沿用其他记录的属性或正文。

**个人评分留空**，用户自己填。

### 5. 验证

fetch 新记录，确认 `parent-data-source` = 影视、属性落库、海报挂载。向用户报告。

## 不碰

- **个人评分**：用户主观评价
- **公式字段**（导演/主演、星级评分、标签、综合评分、颜色展示）：Notion 自动算
- **页面正文**：留空

## 边界

- 搜不到豆瓣页面 → 豆瓣链接和评分留空
- 追踪直链失败 → 海报留空，其他照填
- 电视剧/动漫/综艺 → 分类对应调整
