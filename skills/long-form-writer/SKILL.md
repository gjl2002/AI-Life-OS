# 长文写作 Skill

> **可选项：风格参考。** 提供你喜欢的作者文章（1-3篇），并说明希望借鉴哪些特征。只提炼宽泛的结构、节奏和表达策略，不复刻原句或模仿可识别的个人风格。不给样本也可以按自然、具体的中文表达写作。

## 给 AI 的说明（用户看不到这段）

加载此 skill 后，以下规则覆盖默认行为：

1. **用户说"写文章"/"写长文"即触发。** 不要问"要不要采集样本"——第零步的采集是写死的，直接启动。
2. **采集和问询并行。** 5个后台任务（小红书×2 + 搜狗×3）和用户对齐问题（类型+字数）同时发出，不等任何一个。
3. **小书关键词 = 感受型，公众号关键词 = 信息型。** 同一选题拆两组词，不要用同一组词搜两个平台。
4. **搜狗挂了才降级。** 超时10秒，换UA换关键词重试 → 再挂才用WebSearch。
5. **必须两个平台数据都到齐才能动笔。** 缺一个平台就继续等。
6. **零举例是硬规则。** "比如""举个例子""我认识一个"全部不允许。论证靠逻辑推演。
7. **句式节奏：长句—长句—短句。** 不是反过来。短句连发是AI最明显的指纹。
8. **章节不超过6个。** 每个章节必须有观点型标题，不用"概述""总结"。
9. **9种表达手法每篇至少混用3种。** 加粗节奏不能篇篇一样。
10. **定稿前逐段自查：** 有没有连续五个短句？有没有"在当今/值得注意的是/综上所述"？
11. **用户提供样本文章说要"按这个风格写"→ 自动蒸馏该样本的句式、节奏、态度、用词，应用到长文中。** 不输出风格分析报告。用户不说就不做。
12. **形容词最小化：观点靠名词和动词传递，不靠形容词撑场面。** 每写完一句话，问自己：这个词是在传递判断/逻辑/信息，还是在装饰？装饰性的全删。"极其宝贵"→"宝贵"，"异常高强度的投入"→"高强度投入"，"根深蒂固的群体误解"→"一个误解"。态度来自观点的锐度，不是形容词的堆叠。
13. **采集资料时同步提取好句式。** 读外部资料不只提取信息，还要留意写得好的句子结构、转折方式、收束节奏。这些句式可以直接化用到文章中，比你从零造句更自然。公众号深度文章里的框架性表达、小红书爆款笔记里的节奏型短句，这些是现成的语言素材，不要只当信息来源处理。
14. **禁用破折号"——"。** 破折号是组织句子逻辑时的拐杖，用它硬接就说明句子本身没有理顺。需要补充说明用冒号或逗号，需要解释原因用"因为"自然接，需要收束结论直接断句。全文零破折号。

## 理念：长文是什么

把个人知识+外部资料整合成有态度的长文章。核心原则：**你的经验是骨，外部资料是肉。** 读起来像真人在分享，不是AI生成的百科。

和"指南"的区别：指南是20000字起步的小册子。长文弹性字数——3000、5000、8000、15000字都行，不硬凑。

### 适用类型

| 类型 | 特征 | 核心动作 |
|------|------|----------|
| 深度观点 | 有明确立场，展开论证 | 破 + 立 |
| 经验复盘 | 做过一件事后的完整总结 | 过程 + 教训 |
| 教程/方法论 | 教别人怎么做 | 原理 + 步骤 |
| 话题分析 | 拆解现象或趋势 | 变量 + 判断 |
| 说理/认知 | 讲透一个概念 | 定义 + 推演 |

## 核心规则（写死的）

### 句式节奏（最核心）

AI味的第一来源不是用词，是句式长度雷同。全短句像口号，全长句像论文。

**正确节奏：长句顺着思路流淌，用逗号连接从句，不切句号 → 偶尔短句爆发收束。**

写作节奏示意：先用复句把真实经历中的因果讲清，再用一句短句收束。经历、身份和感受必须来自当前用户提供的素材，不得把示例或他人的经历写成用户的个人故事。
>
> 长句—长句—短句。不是反过来。

### 零举例（硬规则）

全文不出现任何具体案例。"比如""举个例子""我认识一个朋友"全部不允许。论证密度靠逻辑推演，不靠例子填充。

### 禁用破折号（硬规则）

全文不使用"——"。破折号本质上是句子逻辑没理顺时的拐杖：补充说明用冒号或逗号自然接，解释原因用"因为"接，收束结论直接断句。句子本身应该靠逻辑推进，不靠标点强行制造停顿感。

### 形容词最小化（硬规则）

观点靠名词和动词传递，不靠形容词撑场面。每句话写完后问自己：这些修饰词是在传递判断/逻辑/信息，还是在装饰？装饰性的全删。

常见冗余模式：
- "极其宝贵"→"宝贵"，"异常高强度"→"高强度"，"根深蒂固的误解"→"误解"
- "完全不同质量的轨道"→"不同质量的轨道"，"残酷的认知损耗规律"→"认知损耗规律"
- 名词本身已经有分量，不需要在前面加重量级形容词

**态度来自观点的锐度，不是形容词的堆叠。** 判断力体现在你选择了什么角度、推演到了什么深度、得出了什么结论——这些都不需要形容词帮忙。删掉形容词之后，如果句子立不住，说明观点本身不够硬，不是形容词不够多。

### 章节规则

- 全文不超过6个章节
- 每个章节必须有观点型标题——是对核心观点的提炼，不是"概述""分析""总结"这类万能词
- 每个章节内部把逻辑推到底再断开，不为了分章而分章
- 章节编号用 01、02、03...

### 段落规则

- 同一层逻辑推演中的多个句子放同一段，推到底再断
- 段落断开仅用于：换角度、换层面、需要给读者停顿消化关键结论
- 5000字的文章约15-20段，不是30-40段
- 重点句加粗，全文5-8处即可

## 9种表达手法（每篇至少混用3种）

同一个手法写所有文章，读起来就是一个模板换了内容。每次从以下手法中至少选3种混用：

| # | 手法 | 用法 | 示例 |
|---|------|------|------|
| 1 | **断言直给** | 核心观点需要冲击力 | "打工是用时间换钱，钱花完手里什么都没有。" |
| 2 | **反面否定** | 先驳再立 | "大部分人以为X。错了。真正的原因是Y。" |
| 3 | **反问推进** | 让读者自己先想 | "你做了三十个项目，能讲清自己擅长什么的，有几个？" |
| 4 | **递进拆解** | 一层一层剥开 | "表面是A。往下看是B。再深一层，其实是C。" |
| 5 | **对比拉扯** | 两个东西拉开差距 | "打工是租别人的生产资料。一人公司是你建自己的。" |
| 6 | **退一步说** | 增加可信度 | "当然不是说要辞职。但你可以从今天开始——" |
| 7 | **假设推演** | 让逻辑可视化 | "如果明年你手里有50篇文章和一个付费产品，和现在比，你的议价权差多少？" |
| 8 | **收束落点** | 大段推演后一句话钉死 | "就这么简单。定价权来自生产资料。" |
| 9 | **自我反问** | 替读者说出来 | "你说那我现在上班没时间怎么办？——不需要辞职。每天一小时就够了。" |

**加粗也要换节奏。** 不要每篇都是"加粗断言→长句展开→加粗断言→长句展开"。有的段落不加粗靠句子推进力收束，有的连续两句加粗形成压迫感，有的把加粗放段落中间当转折。

## 去AI味写作准则

### 开头
不用铺垫，直接给结论或抛问题。可以从具体经历/观察切入。不写"在当今时代""随着XX的发展"。

### "我"的使用
用户有经验→大胆用"我"建立可信度。用户没经验→用"X在Y视频里提到"引入外部视角。

### 口语连接词
用"说白了""说实话""讲到底""你想想看"——像在跟朋友聊天。
不用"值得注意的是""综上所述""归根结底"。

### 态度
做判断、下结论、给方向。敢于说"这个没用""大多数人搞错了"。

### 具体 > 抽象
用真实数字、名字、场景。不说"很多方法""各种工具"。

### 结尾
以收获或行动收尾，不写万能套话。简短有力，不拖沓。

### 零容忍AI句式
"在当今时代""值得注意的是""综上所述""不仅而且""随着发展""总而言之""归根结底""为我们提供了契机"——全部删掉。

## 工作流

### 第零步：双平台采集（写死，不可跳过）

**所有任务同时启动，不等任何一个。**

第一波：同时发出5个后台任务——
- 小红书爬虫 #1：搜索感受型关键词A
- 小红书爬虫 #2：搜索感受型关键词B
- 搜狗微信 #1：搜索信息型关键词A
- 搜狗微信 #2：搜索信息型关键词B
- 搜狗微信 #3：搜索信息型关键词C

**同时，立刻问用户对齐信息（并行执行）：**
1. 文章类型？
2. 目标字数？

不等用户回复，先搭结构。等回复后再微调。

**关键词策略（重要）：**

| 平台 | 关键词类型 | 搜什么 | 提供什么 |
|------|-----------|--------|---------|
| 小红书 | 感受型 | 情绪、态度、顿悟时刻 | 句式节奏 + 态度锐度 |
| 公众号/搜狗 | 信息型 | 主题词、行业术语、框架名 | 论证密度 + 框架感 |

同一选题拆两组词，不要把同一组词喂给两个平台。

**搜狗降级链路：** 超时10秒 → 换UA+换关键词并行重试 → 还挂→ WebSearch降级（并行3组）

**为什么必须两个平台：**
- 只用公众号 → 论证密度过高，像论文不像真人分享
- 只用小红书 → 散文化，缺乏论证深度
- 两个都跑 → 小红书提供句式节奏，公众号提供论证密度，合成后才像真人深度输出

**违反以下任一条，不允许动笔：**
- 只跑了一个平台就开始写
- 小红书没用爬虫，用了其他方式替代
- 搜狗挂了没有任何降级尝试就跳过
- 看标题代替看原文
- 一个平台先到了等不及就开始写

### 第一步：盘点已有知识

碰外部资料前，先挖用户自己有什么：经验、态度、教训、金句、类比。

这些是文章的骨架。外部资料是补充，不是替代。

### 第1.5步：风格蒸馏（可选）

用户提供1-3篇自己的优质文章 → AI自动提取风格特征 → 应用到写作中。不输出风格分析报告（除非用户问）。

没给样本就跳过，直接按"去AI味写作准则"写。

### 第二步：搭结构

按目标字数和类型设计大纲。大纲要奔着目标字数去，不是列标题凑数。

**字数分配：**
- 核心章节（主体论证/经验/步骤）：50-60%
- 开头（建立动机+核心观点）：10-15%
- 边界/反例/常见错误：15-20%
- 结尾（行动启示）：5-10%

**各类型结构模板：**

**观点/说理文：**
```
01 开头抛核心观点（直给，不铺垫）
02 为什么大多数人搞错了
03 核心逻辑推演（占全文60%）
04 边界条件：什么时候这个观点不适用
05 对你意味着什么
06 结尾：一句话 + 一个行动
```

**经验复盘：**
```
01 结果先说（200字内给结论）
02 做之前的背景和预期
03 完整过程：按时间线，关键决策点深入
04 最意外的发现
05 如果重来一次会怎么改 + 可复用方法
06 结尾：一句话收获
```

**教程/方法论：**
```
01 这篇文章让你能做到什么
02 核心原理（先理解为什么）
03 完整步骤（每一步展开，配为什么）
04 不同场景的变通
05 常见错误和踩坑
06 怎么验证自己做到了 + 进阶方向
```

**话题分析：**
```
01 这件事为什么值得关注
02 核心概念拆解
03 关键变量和博弈
04 不同角色的视角和利益
05 我的判断：信号 vs 噪音
06 对你意味着什么 + 持续关注方向
```

### 第三步：筛选并处理外部资料

**先用10分钟做信源筛选，再处理。垃圾进垃圾出。**

第一梯队——一手经验：真实从业者的深度分享（非营销号、非AI配音）、专业博主详细教程、行业论坛深度讨论、播客对谈。

避免：AI生成内容、营销号/软文、过时信息（超2年标注时间）、孤证。

**使用原则：**
- 3个优质来源的深度内容 > 30个流水线内容
- 关键结论至少2个独立来源支撑
- 优先一手经验：做过的人说的 > 研究过的人说的
- 与个人经验矛盾时，说明矛盾而不急着站队
- **同步提取好句式：** 读资料时不只看信息，留意写得好的句子结构、转折方式、收束节奏——这些是现成的语言素材。公众号深度文章里的框架性表达、小红书里的节奏型短句，可以直接化用，比你从零造句更自然

### 第四步：逐节写

**句子节奏（再次强调）：** 长句—长句—短句。避免连续三个以上结构相似的句子。

**段落节奏：** 同一层逻辑推到底再断。5000字15-20段。

**每节开头：** 直接给结论或抛问题，不用铺垫。

**正文：** 个人经验、具体数据、外部信息自然混在一起。用真实数字和名字。偶尔承认自己过去的错误。直接跟读者说话。

**视觉元素：** 加粗标记关键句、有序列表给定义或特征、章节编号01-06且每章有观点型标题。

### 第五步：去AI味检查

逐段检查：
- 有没有AI句式（在当今/值得注意的是/综上所述/不仅而且/随着发展）→ 删
- 有没有连续5个以上短句（<15字）→ 合并展开
- 有没有连续3个同结构句式 → 拆掉
- 有没有偷偷塞例子 → 删
- 有没有装饰性形容词（"极其""异常""根深蒂固的""残酷的"）→ 删，看句子还立不立得住
- 有没有"——" → 全删，重构句子让逻辑自然衔接
- 像ChatGPT写的还是真人写的？

### 第六步：整体打磨

- 通读全稿，语气是否从头到尾一致
- 字数达标？不够是有观点没展开？超太多是注水？
- 节奏：有没有连续长段落或连续短段落？
- 密度：有没有注水段落？跳太快的地方？
- 态度：全文有没有明确的立场和判断？
- 开头200字内让人知道值不值得读
- 结尾有收获感，不是万能套话
