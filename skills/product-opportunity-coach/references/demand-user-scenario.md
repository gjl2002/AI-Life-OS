# Demand, User, Scenario

Use this for demand strength, first-user choice, and trigger-scene analysis.

## Demand Type

Classify the product's core demand:

- `痛点`: fear-driven. The user acts because they are afraid of a consequence.
- `爽点`: instant satisfaction. The user seeks and quickly receives relief, progress, pleasure, speed, clarity, or control.
- `痒点`: virtual self. The product helps the user feel closer to an ideal self, status, lifestyle, identity, or future image.

Do not call a need a pain point only because it is unmet. Without fear or consequence, label it as `不爽`, `便利需求`, or weak pain.

Hard rule: if no user quote, private-domain question, consultation form, content comment, or repeated observed behavior shows consequence/fear/urgency, do not score pain as strong.

## Demand Probe

```markdown
需求:
痛点:
  用户害怕什么后果:
  证据:

  证据:

  用户想成为/看起来像谁:
  证据:
主抓手:
  痛点 / 爽点 / 痒点 / 混合:
```

## Optional User-Readiness Lens

Use this lens only when it changes acquisition, explanation, onboarding, or product entry. Do not force every user into a label.

- `大明`: need is clear; search-driven; wants price, hard value, speed, certainty, and comparison.
- `笨笨`: need is fuzzy; browse-driven; wants discovery, comparison, examples, stories, and guided choice.
- `小闲`: no active demand; attention/time-killing driven; needs entertainment, identity, curiosity, or social trigger before conversion.

Map product design to user type:

```markdown
首批用户:
用户类型:
为什么会行动:
为什么现在:
即时满足:
转化阻力:
```

If the product is for `笨笨` or `小闲`, do not design the first entry like a search-driven tool page. Use content, cases, guided diagnosis, or scenario packaging first.

## Conditional Community Roles

For community, cohort, course, or network products only, also check:

- `第一只羊`: one user who can get immediate value and stay.
- `头羊`: heavy user / organizer / KOC who can attract or manage similar users.
- `狼`: payer, sponsor, brand, employer, or business side if monetization is not from the sheep.

## Scenario Trigger

Scenario = `场` + `景`.

- `场`: time and space where the user can stay, consume, or act.
- `景`: interaction and emotion that trigger action.

Use this table:

```markdown
触发场景:
时间:
空间/入口:
用户当时在做什么:
情绪触发:
为什么需要立刻解决:
当前替代动作:
产品进入方式:
```

A channel is not automatically a scene. A scene must trigger emotion and action.

If the trigger scene cannot be named, the opportunity cannot be `值得做`; choose `先验证` and design a scene test.
