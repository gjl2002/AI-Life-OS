# 新要素与职业身份变化

当 AI、新工具、新平台或新工作方式进入用户生活时，判断它只是提升原有能力，还是正在改变职业身份与人生方向。

核心问题：

```text
这是旧身份加新工具，还是一个需要重新定义的职业/人生角色？
```

审查：

- 自我介绍是否真的改变
- 日常工作和能力组合是否改变
- 长期想解决的问题是否改变
- 作品、协作方式和责任边界是否改变
- 理想生活是否因此更接近或更远
- 是否已有持续行为和现实结果，而不只是新鲜感

输出判断：`旧身份优化 / 过渡型升级 / 新职业身份假设`。

这个参考只回答人生与职业身份问题。客户、Offer、产品和市场定位应交给 `$commercial-positioning-coach`。
