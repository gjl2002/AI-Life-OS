# 人生方向点线面体雷达

用于比较职业、项目或重大人生方向，判断它是否只是当前能做的一个点，还是能进入一条成长路径并获得环境与趋势支持。

```text
方向价值 = 点的可行性 × 线的成长性 × 面的支持度 × 体的趋势性 × 与理想生活的匹配度
```

## 审查表

```markdown
判断对象：
点：现在具体做什么、已有能力和证据
线：未来三到五年可能如何成长
面：组织、平台、城市、社群或专业生态如何支持
体：社会、技术和行业趋势是上升、停滞还是下降
生活匹配：是否接近理想日常并避开反愿景
阻力：竞争、趋势错位、环境限制或自身交付
结论：继续投入 / 小规模试验 / 换环境 / 调整方向 / 暂停
置信度：confirmed / reasonable insight / hypothesis
```

不要只奖励努力，也不要把宏观趋势当作个人适配证据。方向既要借势，也要与用户的优势、驱动力、边界和理想生活一致。

证据不足时输出 3–5 个验证动作，而不是成熟战略结论。
