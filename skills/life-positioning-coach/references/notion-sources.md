# 人生定位 Notion 云端资料

## 资料边界

- 云端 Notion 是唯一个人资料源；不要读取本地同步、Markdown 镜像、数据库索引或缓存。
- 按数据库名称定位数据源并检查实时 schema；不要依赖固定页面 ID 或记忆中的字段。
- 只读取当前教练阶段所需的记录，不因数据库存在就全量扫描。
- 用户当前说法与历史记录不一致时，保留日期和阶段差异。

## 当前处境

开始时优先读取与当前问题相关的近期信息：

- 近期复盘；
- 当前目标和项目；
- 人生领域；
- 最近几次人生设计。

先整理当前角色、正在发生的变化、当前投入、反复阻力、已有方向假设和资料缺口，再提出第一个问题。

## 阶段资料

| 教练阶段 | 优先读取 |
| --- | --- |
| 当前处境 | 近期复盘、目标、项目、人生领域、最近的人生设计 |
| 优势 | 个人故事、人生时刻、认知笔记 |
| 热爱与驱动力 | 认知笔记、个人故事、历次人生设计 |
| 问题主题 | 问题、个人故事、认知笔记 |
| 现实证据 | 人生时刻、个人故事、项目、复盘 |
| 反愿景 | 认知笔记、个人故事、历次人生设计 |
| 理想自我与愿景 | 历次人生设计、人生旅程、人生领域、目标 |

现行核心资料包括：

- `第二大脑 / 笔记` 中归类为认知笔记的记录；
- `第二大脑 / 问题`；
- `人生探索 / 人生设计` 中按时间保存的一次次设计记录；
- `人生探索 / 个人故事`；
- 按阶段需要补充的人生时刻、人生旅程、人生领域、复盘、目标和项目。

## 读取纪律

- 先限定数据库、分类、状态、日期或关键词，再读取正文。
- 已有记录能够回答的部分直接形成暂定总结，只追问矛盾、变化和证据缺口。
- 对关键判断保留记录标题、日期和来源，供证据审查。
- 找不到资料时标明缺失来源及其对置信度的影响。
- 云端整体不可用时停止检索；只有用户明确同意后，才可仅基于当前对话继续轻量探索。
