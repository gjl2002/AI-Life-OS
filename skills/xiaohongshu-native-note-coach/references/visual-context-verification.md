# Visual Context Verification

## Purpose

Before final output, verify that the title, images, body, proof, and CTA all describe the same reality. This is the Xiaohongshu-specific gate that prevents a note from being smooth but visually unsupported.

## Verification Map

For enhanced, strict, and campaign mode, build this internal map before final drafts:

```markdown
图文一致性：
- 封面承诺：
- 封面是否能证明标题：
- 每张图证明什么：
- 正文关键事实：
- 客户/私域证据来源：
- 产品/CTA来源：
- 里程碑/结果来源：
- 公开/书籍来源：
- 外部来源是否只是背书、还是核心证明：
- 需要打码/裁剪/弱化：
- 不能写成公开结论的点：
- 可放心写的内容：
```

## Image-Led Claim Rules

- A title promise should be visible in the image set or clearly supported by the body evidence.
- A result/milestone claim requires screenshot, Notion evidence, user-provided proof, or clear context.
- A customer result requires customer/private-domain evidence and anonymization.
- Product promise, price, quota, deadline,报名方式, and private-message keyword require current product/offer evidence.
- Benchmark notes can inspire title rhythm, cover logic, and structure, but cannot provide user-owned proof.
- If the image is decorative, do not let the body pretend it is evidence.
- A research, interview, public case, or book can support a judgment, but cannot stand in for user-owned result, product, customer, or milestone proof.
- If an external source is central to the title promise, use a readable source card in a supporting/final image or a pinned comment; do not hide a citation-heavy bibliography in the body.

## Publicability Rules

Before recommending publication, check:
- names, avatars, phone numbers, WeChat IDs, order IDs, company/client details.
- unpublished product details.
- private financial/payment data.
- customer/customer-company information.
- private Notion URLs or database names that should not be public.

Recommend blur, crop, paraphrase, or omit when needed.

## Weaken Instead Of Invent

If proof is incomplete:
- Replace "我靠这套方法做到了..." with "这张图记录的是我最近一次真实推进..."
- Replace "很多人已经有效果" with "有几个反馈让我确认这个方向值得继续做..."
- Replace exact product/price/deadline with "如果你想了解，我可以私信发你当前版本。"
- Replace "普通人都能复制" with "至少这条路径对我来说更可执行。"

## Final Decision

Only deliver a final note when:
- the cover/title/body do not overpromise beyond the images.
- the main proof is real and usable.
- private details are protected.
- unsupported result/product claims are removed or softened.
- the CTA matches verified product/current offer.
